# Sunny Strawkins: Patch Patrol 🌻

A mobile-first, standalone HTML5 scarecrow-merging garden defense game. This is a browser mini-game/spin-off, **not** the full planned PC scarecrow/farm-defense game.

## Current prototype
- Source: [index.html](./index.html), self-contained (CSS, JavaScript, art and audio generated in code)
- Four garden lanes and a tile grid
- Plant scarecrows for 25 straw; tap or drag two of equal level to merge (up to level 4)
- Automatic lane defense, five incoming-bird waves, crow/raven/swift variants
- Pip the puppy's cooldown-based bark ability
- Straw earning, health, score, local high-score storage
- Pause/resume, victory/defeat, restart, touch + mouse controls

## Run
Open `index.html` in a browser. No build tools or external assets needed for this initial prototype.
